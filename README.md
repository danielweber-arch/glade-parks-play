# Glade Parks Builder (browser build)

A city-building game about a young real estate developer in the fictional city of Cedar Glade, Texas.
This repo holds only the built browser version. It runs entirely in your browser (the game engine is
compiled to WebAssembly); there is no server and nothing you do leaves your computer.

Play: open the GitHub Pages link for this repo. Saves stay in your browser.

Everything here is a build artifact. The source is private. Every name, company and place in the game
is fictional.
